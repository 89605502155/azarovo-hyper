# Документация azarovo-hyper

`azarovo-hyper` — высокоуровневая Python-библиотека для создания, настройки и
управления виртуальными машинами KVM и Xen через libvirt. Полностью
настроенный гость поднимается одной строкой:

```python
from azarovo_hyper import hyper

kvm1 = hyper().kvm(iso="~/Загрузки/ubuntu.iso", preset="ubuntu").start()
```

## Поддерживаемые платформы

* Linux-хосты с libvirt (KVM через `qemu:///session` или `qemu:///system`,
  Xen через `xen:///system`);
* Python 3.11, 3.12, 3.13 и 3.14.
